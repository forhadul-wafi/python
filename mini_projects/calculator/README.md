# 🔢 Simple Arithmetic Calculator

A user-friendly command-line calculator built in Python that performs basic arithmetic operations with history tracking and proper error handling.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## ✨ Features

- **7 Arithmetic Operations**: Addition, Subtraction, Division, Multiplication, Power, Modulus, and Floor Division
- **Calculation History**: View all previous calculations during the session
- **Smart Input Validation**: Prevents division by zero and handles invalid inputs gracefully
- **Clean Interface**: Easy-to-use menu-driven program
- **Formatted Output**: Results displayed with 2 decimal places
- **Error Handling**: Robust `try-except` for non-numeric inputs
