# Python Learning Journey 🐍

My personal repository for learning Python. It contains topic-wise practice, small complete projects, and problem-solving exercises from HackerRank.

## 📁 Project Structure

| Folder | Description |
|---|---|
| `mini_projects/` | Small complete applications |
| `topics/` | Topic-wise practice exercises |
| `topics/lists/` | List-related problems |
| `topics/tuples/` | Tuple-based programs |
| `hackerrank-problems/` | Solutions to HackerRank practice problems |

## 📌 Mini Projects

- Simple Calculator
- Number Guessing Game
- Menu System Calculator
- Login System

## 🚀 Topics Covered

- Lists
- Tuples
- Conditional logic
- Basic input/output
- Problem solving with HackerRank

## ▶️ How to Run

1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Clone the repository:
   ```bash
   git clone https://github.com/forhadul-wafi/python.git
   cd python
   ```
3. Run any file:
   ```bash
   python mini_projects/<file_name>.py
   ```
